Open source

CORTEX

Public on GitHub, Early

CORTEX is an open-source framework for building software around large language models (LLMs): agents, the tools they call, and the messages agents send each other. It is written in Python and published under the MIT License.

The README lists four parts, each with its own status:

  • YAMCP: a tool server that works over several connection types. In testing (v0.1).
  • A2A: messages between agents. Coming soon.
  • Schema: one builder for API and function specs. Drafting.
  • Planner: decides which tools and agents to call for a multi-step task. On the roadmap.

Part of CORTEX

YAMCP

In testing, v0.1

YAMCP (“Yet Another Model Context Protocol”) is the tool server inside CORTEX. You wrap an API or a piece of business logic as a tool, and an AI agent can find it and call it. New tools are added as plugins, and the server can be reached over HTTP, WebSocket or the command line. It is built with FastAPI and Pydantic.

Experiments around a vision

Brain

Research experiments

Brain is a series of experiments toward one vision: an open-source AI companion modelled on how the human brain actually works, from memory and attention to awareness of itself and the people around it. Each experiment starts from existing neuroscience and AI research and tests one piece of that idea. It isn’t a product. It’s where we explore what a truly brain-like companion could be, and we’ll share notes and findings here as the experiments mature.
