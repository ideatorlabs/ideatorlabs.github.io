ideatorlabs/cortex ↗

Public on GitHub

CORTEX is a framework for building software around large language models (LLMs): agents, tool servers, and the messages agents send each other. Its README describes it as composable: you plug in the parts you need.

Inside CORTEX

YAMCP ↗

In testing, v0.1

YAMCP is a Model Context Protocol (MCP) tool server. You wrap an API or a piece of business logic as a tool, and an AI agent can find it and call it. Tools are added as plugins, without changing the core. It can be reached over HTTP, WebSocket or the command line, and it is built with FastAPI and Pydantic. It lives in the yamcp folder of the CORTEX repository; it is not a separate package.

Python packages

Small tools from our products, free to use

Five plug-and-play Python packages taken from the software we build. Each has its own documentation, runs on Python 3.10 and newer, is tested on every change and is Apache-2.0 licensed.

WhatsApp Cloud API engine

Greenline

Run WhatsApp Business messaging for many businesses from your own server. It replies inside the 24-hour window, falls back to an approved template outside it, checks signed webhooks, honours STOP and START, and keeps a running cost per message.

$ pip install "greenline @ git+https://github.com/ideatorlabs/greenline"
Documentation ↗ GitHub ↗
POS and spreadsheet connectors

TillSync

Pull customers and bills from point-of-sale systems, JSON APIs, Google Sheets and CSV or Excel files into one clean shape. It guesses which column is which, explains each guess and lets you correct it.

$ pip install "tillsync @ git+https://github.com/ideatorlabs/tillsync"
Documentation ↗ GitHub ↗
Personal message lines, with reasons

Nudgewright

Write one short, personal line for a customer from the facts you really have: a festival this week, their usual order, the offer the owner set. It never invents an offer, keeps sensitive businesses to plain wording, and says why it wrote what it wrote.

$ pip install "nudgewright @ git+https://github.com/ideatorlabs/nudgewright"
Documentation ↗ GitHub ↗
Exception alerts for Python

Faultbell

Get one clean alert per problem when a Python service or cron job fails, in Discord, Slack, Microsoft Teams, Google Chat, Telegram, PagerDuty or email. Secrets are scrubbed, repeats are grouped, and it never slows a request down. Version 0.2 adds a server watch: bursts of errors on a route, memory above 80% and crashes without a clean shutdown each raise an alert.

$ pip install "faultbell @ git+https://github.com/ideatorlabs/faultbell"
Documentation ↗ GitHub ↗
Lead capture and business alerts

Leadbell

Capture website leads properly: required consent with the exact wording version stored, a hidden spam trap, rate limiting and the visitor’s first source. Then get one card per sign-up, lead or payment in Discord, Slack or any webhook.

$ pip install "leadbell @ git+https://github.com/ideatorlabs/leadbell"
