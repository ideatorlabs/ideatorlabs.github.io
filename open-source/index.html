ideatorlabs/cortex ↗

Public · Early

CORTEX is a framework for building software around large language models (LLMs): agents, tool servers, and the messages agents send each other. Its README describes it as composable: you plug in the parts you need.

Part What it does Status in the README
YAMCP Tool server with plugins, over several connection types In testing (v0.1)
A2A Messages between agents Coming soon
Schema One builder for API and function specs Drafting

Inside CORTEX

YAMCP ↗

In testing · v0.1

YAMCP is a Model Context Protocol (MCP) tool server. You wrap an API or a piece of business logic as a tool, and an AI agent can find it and call it. Tools are added as plugins, without changing the core. It can be reached over HTTP, WebSocket or the command line, and it is built with FastAPI and Pydantic. It lives in the yamcp folder of the CORTEX repository; it is not a separate package.
